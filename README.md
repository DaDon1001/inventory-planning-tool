# Inventory Planning Tool 2025

Inventory plan for 9 children-shirt SKUs, built as a university assignment.

- **Task 1:** inventory levels, safety stock and resupply planning
- **Task 2:** inventory value and cash flow
- **Task 3:** freight volume consolidation: boxes, Euro pallets and freight cost per customer, daily vs weekly dispatch (dashboard page 09, standalone workbook)

## Contents

- `index.html`: interactive dashboard (runs fully offline in the browser, no external libraries)
- `Inventory_Tool_Task1_Task2.xlsx`: the Excel tool for Tasks 1 and 2
- `Task3_Freight_Consolidation.xlsx`: the standalone Task 3 workbook (English, live formulas, built only from the sales order dataset)
